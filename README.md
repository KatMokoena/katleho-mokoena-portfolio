# Katleho Mokoena

Portfolio site for Katleho Mokoena, Full Stack Software Engineer.

Live site: https://katmokoena.github.io/katleho-mokoena-portfolio/

The React source is in `site/`. GitHub Pages serves the built files in this folder (`index.html` and `assets/`).

```bash
cd site
npm install
npm run dev
```

Open http://localhost:5173/katleho-mokoena-portfolio/

```bash
npm run build
```

That writes the static site into this folder. Commit those files and push to `main` to update the live site.
